# Privacidad de las apps de Eicart

Página pública para Magic Life, Cacho, Turno Arcano, Dados Arcanos y Forja de Nombres.

Contacto: watchwheel.soporte@gmail.com.

## Publicación en GitHub Pages

Repositorio previsto: Eicart/apps-privacy, público.
En Settings → Pages, selecciona Deploy from a branch, rama main y carpeta / (root).
La dirección prevista es https://eicart.github.io/apps-privacy/. Esta URL solo debe usarse después de confirmar que GitHub Pages publicó correctamente.

La página es HTML estático, sin scripts, cookies ni recursos externos. No contiene código de las apps ni claves de firma.
